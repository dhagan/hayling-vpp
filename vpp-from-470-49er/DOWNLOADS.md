# Flying Dutchman / 470 / 49er VPP and polar source inventory

**Source sweep/access date:** 2026-11-08

**Scope:** Public class-association/federation pages, sailing-performance simulators/data repositories, Olympic tracking pages, and technical publications that could provide Flying Dutchman (FD), 470, or 49er numeric performance/polar information. Only sources actually checked are described here; this is not a claim of exhaustive coverage.

## Findings at a glance

Two public 49er `.pol` tables and 2018/2020 spreadsheet files are downloaded
under `downloads/`. The text matrices are structurally valid, but their units
and original calculation source are not documented by the `.pol` index. The
spreadsheet HOWTO says its source polar CSV is obtained from Regatta Game, so
the workbooks are game-derived, not verified real-world 49er measurements or
an authoritative class VPP. The `.pol` files' relationship to those workbooks
is plausible from their class/year labels, but not explicitly documented;
treat their lineage as unverified.

No raw numeric FD or 470 polar has been verified or downloaded. The FD class
site provides useful dimensions, rig/sail areas, boat weights, tuning guides,
and a crew/equipment review, but no TWS/TWA performance matrix. Its "up to 20
knots" statement is an unqualified speed claim, not a measured polar point.
Tactical Sailing publishes 470 and 49er diagrams and describes their basis as
professional sailors' practical experience plus VPP data; its page does not
expose a numeric table. No numerical data from those images were copied.

## Gaps and interpretation

- **Actual numerical FD or 470 polar:** none verified/downloaded. The FD class site provides technical specifications and a crew/equipment review, not a wind-angle/wind-speed polar. Tactical Sailing exposes 470 and 49er graphical profiles, not numeric tables. Seapilot's library listing and SailGrib's product page were inaccessible (HTTP 403). The 2020 470 paper is a useful technical lead, but its accessible metadata is insufficient to establish that it publishes a numerical polar; the publisher marks it closed access. No copy is included.
- **49er numeric data:** the downloaded tables are usable as a candidate simulator comparison after units and conventions are confirmed. The associated workbook instructions explicitly cite Regatta Game as the input source, so these must not be represented as measured 49er performance or a validated VPP.
- **Measured material:** the 49er class report gives one top-speed figure, not enough to build or validate a polar. It is not a wind-angle/wind-speed performance matrix.
- **Simulator output:** the checked VR simulator is for game boats and does not include either target class in the checked dataset folders. It must not be presented as real 470/49er performance.
- **Official sources:** 470.org returned 403; no controls were circumvented. The FD class site provides specifications and links to trim/equipment material but no polar. The accessible 49er site searches surfaced descriptive/event/speed-attempt content, not a polar dataset. The World Sailing Paris tracking page did not expose raw tracks to the page fetch.
- **Further work:** obtain authorized access to the 470 research paper and verify tables/figures; request access to Seapilot's 470 polar if available; search class-specific instrumented datasets and national-federation technical archives. For the 49er files, confirm units, calculation method, and reuse terms with the host. Any future polar should record TWS/TWA definitions, speed reference, configuration, conditions, and license.

This inventory records a bounded source sweep, not a complete catalog of every public or privately circulated file.
