# 505 parameter register

Numbers below are rule limits or class-definition values, not necessarily the
dimensions of the particular boat to be modeled. The linked rule PDF is
identified in its metadata as a 2014 rules document; verify the current
amendments before locking inputs.

| Input | Value | Status and use |
|---|---:|---|
| Class LOA | 5.05 m | Class definition, Rule 1.1 |
| Overall hull length | 5.050 m | Measurement form; confirm target hull measurement |
| Station 3 / 6 / 9 positions | 3.810 / 2.438 / 1.066 m forward of Station 11 | Measurement form datum positions |
| Station 3 / 6 / 9 template widths | 1.350 / 1.880 / 1.790 m | Rule measurement-template values, not a complete hull offsets table |
| Minimum dry sailing weight | 127.4 kg | Without sails/battens, dry after prescribed period; not displacement |
| Centerboard maximum extension | 1.450 m below hull | Rule limit, not actual board geometry |
| Mast top point maximum | 7.011 m above mast datum | Rule limit |
| Mast position from Station 11 | 3.048–3.202 m forward | Rule limit, depends on mast datum |
| Boom overall maximum length | 3.308 m | Rule limit |
| Boom outer-point distance maximum | 2.858 m | Rule limit |
| Mainsail leech maximum | 6.960 m | Rule limit; actual sail outline required |
| Headsail luff / foot / leech maxima | 4.510 / 2.287 / 4.000 m | Rule limits; actual sail outline required |
| Spinnaker leech / foot median / foot / half-width maxima | 6.000 / 7.096 / 4.500 / 4.500 m | Rule limits; actual sail outline required |

## Inputs not yet established

- Target boat designer, build year, hull line plan/offsets, appendage geometry,
  and measured hull condition.
- All-up displacement and longitudinal/vertical centers of gravity for the
  target boat and sailing configuration.
- Crew masses and transverse/longitudinal positions as a function of heel,
  wind, and point of sail.
- Hull hydrostatic righting-arm curve and resistance versus speed/heel/leeway.
- Centerboard/rudder area, section, span, wetted area, and lift/drag data.
- Measured mainsail, jib, and spinnaker outlines/camber and aerodynamic force
  coefficients.
- Mast bend/rig state, sail trim, and downwind configuration.
- Sea-state and current assumptions for each polar.

Do not silently replace these missing boat-specific inputs with generic values.
